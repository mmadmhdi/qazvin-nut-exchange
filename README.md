# خانه پسته قزوین

یک وب‌سایت حرفه‌ای فارسی و کاملاً RTL برای نمایش و مدیریت قیمت محصولات خشکبار بساز. هویت بصری باید ترکیبی الهام‌گرفته از منطق داشبورد و چارت‌های TradingView و مینیمالیسم لوکس Monolith NYC باشد، اما کپی مستقیم هیچ‌کدام نباشد. برند باید حس old money، اصالت، تجارت خانوادگی، کیفیت ممتاز و اعتماد را منتقل کند. اولویت اصلی سایت پسته است و سایر محصولات در نقش مکمل دیده شوند.

نام پیشنهادی برند: «خانه پسته قزوین» با امکان تغییر آسان نام و لوگو در پنل مدیریت.

محصولات و قیمت اولیه:
- خلال بادام درختی — 21,000,000
- خلال پسته قزوین — 57,000,000
- خلال پسته بویین — 52,000,000
- خلال بادام زمینی درشت — 5,500,000
- خلال بادام زمینی درجه 2 — 5,200,000
- پرک بادام درختی — 21,000,000
- پرک بادام زمینی — 5,500,000

قیمت‌ها را دقیقاً با همین اعداد ذخیره کن و در UI با جداکننده هزارگان فارسی نمایش بده. واحد قیمت را به‌صورت «ریال» نمایش بده، ولی در تنظیمات مدیریت قابل تغییر باشد.

ساختار سایت:
1) صفحه اصلی با هدر بسیار شیک، لوگوتایپ کلاسیک، منوی خانه/بازار پسته/سایر محصولات/درباره ما/تماس، و CTA برای «مشاهده بازار امروز».
2) هیرو سکشن با تمرکز روی خلال پسته قزوین و بویین، تایپوگرافی لوکس، پس‌زمینه کرم گرم یا سبز زیتونی عمیق، خطوط طلایی بسیار ظریف، بدون شلوغی.
3) بخش «تابلوی قیمت امروز» شبیه منطق واچ‌لیست TradingView اما با ظاهر old money: کارت‌های قیمت، درصد تغییر روزانه نمونه، وضعیت صعودی/نزولی، تاریخ آخرین بروزرسانی، محصول پسته در بالای لیست و برجسته‌تر.
4) نمودار تعاملی قیمت برای هر محصول با انتخاب بازه 7 روزه، 1 ماهه، 3 ماهه، 1 ساله. از Recharts یا کتابخانه مشابه استفاده کن. چارت باید قابلیت tooltip، grid ظریف، axis خوانا و تغییر محصول داشته باشد. ظاهر چارت باید کلاسیک و لوکس باشد: پس‌زمینه کاغذی/کرم، خطوط زیتونی یا طلایی تیره، گوشه‌های نرم و بدون حس کریپتویی یا نئونی. داده اولیه نمونه تولید کن ولی ساختار داده را طوری طراحی کن که بعداً از پنل مدیریت قابل ثبت و ویرایش باشد.
5) بخش «محصولات ممتاز» با دو محصول اصلی پسته در کارت‌های بزرگ و لوکس و بقیه محصولات در کارت‌های کوچک‌تر.
6) صفحه اختصاصی هر محصول شامل نام، قیمت فعلی، نمودار تاریخی، مشخصات، منشأ محصول، درجه کیفی، آخرین بروزرسانی و CTA تماس/استعلام.
7) صفحه درباره ما با روایت برند خانوادگی و اصیل، متن نمونه حرفه‌ای و قابل ویرایش.
8) صفحه تماس با فرم ساده، شماره تماس و آدرس نمونه قابل ویرایش.

پنل مدیریت داخلی بساز با مسیر /admin و UI تمیز و ساده که فعلاً بدون احراز هویت پیچیده قابل مشاهده باشد، اما ساختارش آماده اتصال به auth باشد. امکانات پنل:
- افزودن/ویرایش/حذف محصول
- ویرایش نام محصول، قیمت، واحد، دسته، توضیح، اولویت نمایش
- ثبت تاریخچه قیمت با تاریخ و مقدار
- مدیریت داده‌های نمودار
- فعال/غیرفعال کردن محصول
- تغییر محصول ویژه/اولویت پسته
- ویرایش نام برند، متن هیرو، اطلاعات تماس و درباره ما
- پیش‌نمایش سریع تغییرات
- ذخیره داده‌ها فعلاً با localStorage یا mock backend تمیز، با معماری قابل ارتقا به Supabase

دیزاین سیستم:
- RTL کامل و فونت فارسی حرفه‌ای از منابع قابل استفاده عمومی مثل Vazirmatn یا Estedad
- پالت: سبز جنگلی تیره، زیتونی، کرم استخوانی، بژ، طلایی مات، قهوه‌ای تیره
- حس old money: serif مناسب برای تیترهای لاتین/نشان، فاصله‌گذاری زیاد، borderهای ظریف، سایه بسیار کم، بافت کاغذی ملایم، جزئیات brass/gold بدون اغراق
- بدون گرادیان‌های مدرن جیغ، بدون glassmorphism، بدون رنگ نئونی
- واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- انیمیشن‌های بسیار ظریف و باوقار
- دسترس‌پذیری مناسب، کنتراست خوب، focus states و keyboard navigation

جزئیات فنی:
- React + TypeScript + Tailwind + shadcn/ui
- کامپوننت‌های reusable برای PriceCard، ProductCard، MarketChart، AdminProductForm، PriceHistoryTable
- داده اولیه کامل برای هر 7 محصول
- routing استاندارد
- localStorage persistence
- فرمت تاریخ شمسی در UI در صورت امکان و fallback مناسب
- کد تمیز و ساختاریافته

صفحه نهایی باید از نظر جزئیات، spacing، تایپوگرافی، چارت، hover state، empty state، loading skeleton و responsiveness حرفه‌ای باشد. سایت را به‌صورت کامل بساز، نه فقط یک صفحه استاتیک یا ماکاپ.
